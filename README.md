# Credit Risk Intelligence

Credit Risk Intelligence is an end-to-end machine learning project designed to predict the probability of loan default and support credit-risk decision making. The project will cover the complete ML lifecycle, including data exploration, financial feature engineering, model training and comparison, explainable AI using SHAP, a FastAPI prediction service, and an interactive Streamlit dashboard.
